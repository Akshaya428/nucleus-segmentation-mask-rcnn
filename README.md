# Nucleus Segmentation using Mask R-CNN

## Overview
This project implements instance segmentation of cell nuclei using Mask R-CNN,
aimed at improving automated analysis of microscopy images.

## Dataset
- Data Science Bowl 2018
- Microscopy images with nuclear masks

## Methodology
- Mask R-CNN architecture
- Image preprocessing and augmentation
- Training and evaluation using PyTorch

## Results
- Mean IoU: 0.602
- mAP: 0.443
- Effective segmentation of overlapping nuclei

## Tools & Technologies
Python, PyTorch, Mask R-CNN, Google Colab

## Future Improvements
- Hyperparameter tuning
- Model optimization
